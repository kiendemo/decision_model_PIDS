# PIDSMaker baselines: provenance

Upstream: PIDSMaker commit `2289cd9` (Apache-2.0), run in its own environment. The worktree the runs used carried local diffs relative to that commit: the optc_h501 database name (`optc_501` -> `optc_h501`, pidsmaker/config/config.py); a chunked eval-mode TGN memory flush (pidsmaker/tgn.py, same result); attack-injection hooks that are inert when unset (mimicry.py, a masquerade option in build_default_graphs.py, labelling.py, pipeline.py). Hyperparameters: `pidsmaker_args.sh` (a copy of the job script): docs/tuned_systems.md args where that file has them, config defaults elsewhere; tgn_neighbor_size=10 for the TGN systems on optc_h501 (RAM).

Rows (`pidsmaker_rows.csv`, regenerated by `python scripts/export_baselines.py` on the server; full precision, floats written as repr): one row per clean run and epoch policy. `best_adp` = PIDSMaker's own best-model selection, max (adp_score, discrimination), computed on the TEST labels - a label-selected epoch; `last` = the final epoch; `best_adp=last` when they coincide. Primary columns: the oracle best-MCC confusion on the run's OWN node set and y_truth; `*_H`: the same on the HABITUS universe with the habitus labels, universe nodes the run never scored ranked last; `pm_*`: PIDSMaker's own-threshold confusion (stats file), `pm_recomputed_match` = recomputed from y_preds.

Runs: `orthrus` (ORTHRUS), `orthrus_non_snooped` (ORTHRUS-ns), `orthrus_ns_def` (ORTHRUS-ns), `kairos` (KAIROS), `kairos_def` (KAIROS), `velox` (Velox), `velox_def` (Velox), `nodlink` (NodLink), `nodlink_def` (NodLink), `magic` (MAGIC), `threatrace` (ThreaTrace), `flash` (Flash), `rcaid` (R-CAID). Attacked runs (masquerade, mimicry) are never listed.

Config labels: `tuned*` for `orthrus_non_snooped`, `kairos`, `velox`, `nodlink` on CADETS_E3, THEIA_E3, CLEARSCOPE_E3, optc_h501; `original` for ORTHRUS; `default` otherwise.

Flags:

- S = not label-free / transductive: its embedding (ORTHRUS word2vec, R-CAID doc2vec) is trained on every split including the test window
- T = MAGIC port: the kNN reference of each test window is 5,000 random nodes of that same window (attack nodes included), unseeded
- D = degenerate port score (a type-prediction confidence, not an anomaly score); PIDSMaker's direction kept (higher = more anomalous), no sign flip: a direction is never chosen with labels
- tuned* = docs/tuned_systems.md args (provenance unclear, possibly chosen on test data); the default rows are the fairer ones
- n10 = tgn_neighbor_size=10 (RAM limit) instead of the default 20

Not evaluated (see `pidsmaker_missing.csv`):

- CADETS_E3 R-CAID [default] `rcaid`: no run
- THEIA_E3 R-CAID [default] `rcaid`: no run
- CLEARSCOPE_E3 R-CAID [default] `rcaid`: unfinished
- optc_h501 R-CAID [default] `rcaid`: no run
- ATLASV2_EDR ORTHRUS-ns [default] `orthrus_ns_def`: finished without eval output (cache hit of a run with the same config)
- ATLASV2_EDR KAIROS [default] `kairos_def`: finished without eval output (cache hit of a run with the same config)
- ATLASV2_EDR Velox [default] `velox_def`: finished without eval output (cache hit of a run with the same config)
- ATLASV2_EDR NodLink [default] `nodlink_def`: finished without eval output (cache hit of a run with the same config)

The upstream score files (~8.5 GB of torch pickles, loaded with weights_only=False: trusted local files only) are not shipped; external users get these CSV rows and the best-baseline vectors in the cache bundle only.
